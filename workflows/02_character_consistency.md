# 02 – Character Consistency Workflow (najdôležitejšie)

## Cieľ
Držať rovnakú tvár a telo naprieč všetkými generáciami.

## Odporúčaná kombinácia (2026)
1. **IP-Adapter FaceID Plus V2** (váha 0.6–0.8)
2. **InstantID** alebo **PuLID** (voliteľne)
3. **Character LoRA** (váha 0.8–0.95)
4. **NSFW unlock LoRA**

## Postup
1. Nahraj 1–3 referenčné fotky modelky do IP-Adapter / FaceID
2. Načítaj Character LoRA
3. Generuj s nízkym denoise (0.4–0.65) ak robíš img2img
4. Pre text2img nechaj FaceID + LoRA bežať naplno

## Odporúčané váhy
- FaceID: 0.65 – 0.75
- Character LoRA: 0.85
- NSFW unlock: 0.7
- Detail skin LoRA: 0.4 – 0.6

- Front view

- Smile / Neutral / Seductive
